# 사용자 인증 기능 구현 (Authentication)

## 1. 프로젝트 개요

모바일 애플리케이션 환경을 기준으로 Spring Security 기반의 사용자 인증 구조를 학습하고 구현한 프로젝트이다.

이메일과 비밀번호를 이용한 로컬 로그인, OAuth 기반 소셜 로그인, 게스트 계정 로그인 및 계정 전환 기능을 구현하며, JWT를 활용한 모바일 클라이언트의 인증 흐름을 실습한다.

**주요 목표**
- 모바일 클라이언트와 서버 간 인증 구조 이해
- Spring Security 기반 인증 및 인가 구조 이해
- JWT 발급 및 모바일 클라이언트의 토큰 관리
- 비밀번호 암호화 및 검증
- OAuth 2.0 기반 소셜 로그인 구현
- 게스트 계정 생성 및 일반 계정 전환 흐름 이해

## 2. 기술 스택

- **Backend**: Spring Boot, Spring Security
- **Authentication**: JWT, OAuth 2.0
- **Password**: BCrypt
- **Social Login**: Kakao OAuth

## 3. 주요 기능

### 3.1 로컬 로그인
- 이메일 및 비밀번호 기반 회원 인증
- 비밀번호 암호화 및 검증
- 로그인 성공 시 JWT 발급
- JWT 기반 인증 및 사용자 정보 확인
- 로그인 실패 시 HTTP 401 응답 처리

### 3.2 소셜 로그인 (OAuth 2.0)
- 카카오 OAuth 로그인 구현
- OAuth 인증 결과를 이용한 사용자 인증 및 계정 처리
- 구글 및 네이버 로그인은 미구현

### 3.3 게스트 계정
- 게스트 계정 로그인 기능
- 게스트 계정에서 로컬 계정으로 전환
- 게스트 계정에서 소셜 계정으로 전환하는 기능은 미구현

## 4. API 명세

Base URL: `/api/auth`

| Method | Endpoint | 설명 |
|---|---|---|
| POST | `/guest` | 게스트 로그인 |
| POST | `/signup` | 회원가입 및 게스트 계정 전환 |
| POST | `/login` | 로컬 로그인 |
| POST | `/logout` | 로그아웃 |
| GET | `/login/success` | 소셜 로그인 성공 후 토큰 전달 |
| POST | `/refresh` | 토큰 재발급 |

## 5. JWT 토큰 관리

모바일 클라이언트에서 로그인 상태를 유지하고 인증된 API 요청을 처리할 수 있도록 Access Token과 Refresh Token을 발급한다.

- **Access Token**: API 요청 시 사용자 인증
- **Refresh Token**: Access Token 만료 시 토큰 재발급

발급받은 토큰은 모바일 클라이언트의 안전한 저장소에 보관하며, 인증이 필요한 요청에는 Access Token을 전달한다.

```http
Authorization: Bearer {accessToken}
```

## 6. 인증 기능 구현 현황

| 기능 | 구현 상태 |
|---|---|
| 이메일/비밀번호 로그인 | 완료 |
| JWT 발급 및 인증 | 완료 |
| 비밀번호 암호화 및 검증 | 완료 |
| 로그인 실패 처리 (401) | 완료 |
| 카카오 로그인 | 완료 |
| 구글 로그인 | 미구현 |
| 네이버 로그인 | 미구현 |
| 게스트 계정 로그인 | 완료 |
| 게스트 → 로컬 계정 전환 | 완료 |
| 게스트 → 소셜 계정 전환 | 미구현 |

## 7. 인증 흐름

- **로컬 로그인**: 이메일 및 비밀번호 검증 → JWT 발급 → 인증된 요청 처리
- **카카오 로그인**: 카카오 OAuth 인증 → 사용자 정보 확인 → 로그인 처리
- **게스트 로그인**: 게스트 계정 생성 및 인증 처리
- **계정 전환**: 게스트 계정에서 로컬 계정으로 전환

## 8. 향후 개선 사항

- 구글 OAuth 로그인 추가
- 네이버 OAuth 로그인 추가
- 게스트 계정의 소셜 계정 연동 및 전환 정책 수립
- 기존 게스트 데이터와 소셜 계정 데이터의 병합 및 중복 처리 방안 검토

## 9. 작업 결과

모바일 애플리케이션을 위한 인증 기능으로 로컬 로그인, JWT 기반 인증, 카카오 소셜 로그인 및 게스트 계정에서 로컬 계정으로 전환하는 기능을 구현하였다.

이를 통해 Spring Security 기반의 인증 구조와 JWT 및 OAuth를 활용한 다양한 로그인 방식, 모바일 클라이언트와 서버 간의 인증 흐름을 학습하였다.

일부 소셜 로그인 및 계정 전환 기능은 미구현 상태이나, 현재 학습 및 구현 목표에 따라 작업을 마무리하였다.
